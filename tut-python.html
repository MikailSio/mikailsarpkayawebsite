CORE

Python is the language of data science, AI, and rapid development. Clean syntax, powerful libraries, and a massive ecosystem make it the first choice for NLP and ML engineers. Master the fundamentals here — everything else builds on top.

Level: Beginner → Intermediate
Lessons: 6
Runtime: Python 3.10+
L01
Syntax, Variables & Data Types
int, float, str, bool, None · type() · f-strings · 8 min read
+

Python uses indentation instead of braces. No semicolons, no type declarations — just clean, readable code. Variables are dynamically typed, meaning the type is inferred at runtime.

Python
# Variables — no type declaration needed
name    = "Mikail"
age     = 26
gpa     = 3.85
active  = True
nothing = None

# type() — check the type at runtime
print(type(name))    # <class 'str'>
print(type(age))     # <class 'int'>
print(type(gpa))     # <class 'float'>

# f-strings — the modern way to format strings (Python 3.6+)
print(f"Name: {name}, Age: {age}")
print(f"GPA: {gpa:.2f}")   # format to 2 decimal places

# Multiple assignment
x = y = z = 0
a, b, c = 1, 2, 3   # tuple unpacking

# Type conversion
s = str(42)       # "42"
n = int("100")    # 100
f = float("3.14") # 3.14

Strings in Python are immutable sequences. They support slicing, indexing, and dozens of built-in methods.

Python — Strings
s = "Hello, Python!"

print(s[0])        # H
print(s[-1])       # !
print(s[0:5])      # Hello
print(s[::-1])     # !nohtyP ,olleH  (reversed)
print(s.upper())   # HELLO, PYTHON!
print(s.lower())   # hello, python!
print(s.replace("Python", "World"))  # Hello, World!
print(s.split(","))  # ['Hello', ' Python!']
print(s.strip())    # removes leading/trailing whitespace
print(len(s))       # 14
Tip: Use f-strings over .format() or % formatting — they're faster and more readable.
L02
Lists, Tuples, Dicts & Sets
Core data structures · comprehensions · when to use what · 10 min read
+

Python's built-in data structures are powerful and expressive. Choosing the right one matters for performance and readability.

Python — List
# List — ordered, mutable, allows duplicates
langs = ["Python", "C", "C++", "JavaScript"]

langs.append("C#")       # add to end
langs.insert(1, "Rust")  # insert at index 1
langs.remove("C")        # remove by value
popped = langs.pop()      # remove and return last
langs.sort()              # sort in place
langs.reverse()           # reverse in place

print(langs[0])           # first element
print(langs[-1])          # last element
print(langs[1:3])         # slice
print(len(langs))          # length
print("Python" in langs)  # membership test

# List comprehension — Pythonic way to build lists
squares  = [x**2 for x in range(10)]
evens    = [x    for x in range(20) if x % 2 == 0]
words    = [w.upper() for w in langs if len(w) > 2]
Python — Dict & Set
# Dictionary — key-value pairs, ordered (3.7+), mutable
person = {
    "name": "Mikail",
    "age": 26,
    "field": "NLP"
}

person["university"] = "Korkut Ata"  # add key
del person["age"]                    # remove key
print(person.get("name", "Unknown")) # safe access
print(person.keys())
print(person.values())
print(person.items())               # (key, value) pairs

# Dict comprehension
squares = {x: x**2 for x in range(5)}  # {0:0, 1:1, 2:4, 3:9, 4:16}

# Tuple — ordered, IMMUTABLE
coords = (40.7128, -74.0060)
lat, lon = coords              # unpacking

# Set — unordered, unique values
tags = {"nlp", "ml", "python", "nlp"}  # duplicates removed
tags.add("deep learning")
tags2 = {"python", "data"}
print(tags & tags2)   # intersection
print(tags | tags2)   # union
print(tags - tags2)   # difference
When to use what: List for ordered sequences, Dict for key-value lookups (O(1)), Set for uniqueness/membership tests, Tuple for immutable data.
L03
Functions, Lambdas & Decorators
*args, **kwargs · closures · @decorator · 10 min read
+

Functions are first-class objects in Python — they can be passed as arguments, returned from other functions, and assigned to variables. This enables powerful patterns like decorators.

Python — Functions
# Basic function with type hints (recommended)
def greet(name: str, greeting: str = "Hello") -> str:
    return f"{greeting}, {name}!"

print(greet("Mikail"))             # Hello, Mikail!
print(greet("Mikail", "Hi"))     # Hi, Mikail!

# *args — variable positional arguments
def total(*args: float) -> float:
    return sum(args)

print(total(1, 2, 3, 4))  # 10

# **kwargs — variable keyword arguments
def profile(**kwargs):
    for k, v in kwargs.items():
        print(f"  {k}: {v}")

profile(name="Mikail", field="NLP", city="Osmaniye")

# Lambda — anonymous one-liner function
square = lambda x: x ** 2
add    = lambda x, y: x + y

nums = [3, 1, 4, 1, 5, 9]
nums.sort(key=lambda x: -x)    # sort descending

# map / filter / reduce
doubled  = list(map(lambda x: x*2, nums))
positive = list(filter(lambda x: x > 3, nums))
Python — Decorators
import time
from functools import wraps

# A decorator wraps a function to add behavior
def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start  = time.perf_counter()
        result = func(*args, **kwargs)
        end    = time.perf_counter()
        print(f"{func.__name__} took {end-start:.4f}s")
        return result
    return wrapper

@timer
def slow_sum(n: int) -> int:
    return sum(range(n))

slow_sum(10_000_000)   # slow_sum took 0.2341s
Note: Always use @wraps(func) inside your decorator wrapper — it preserves the original function's name and docstring.
L04
OOP — Classes & Objects
__init__ · inheritance · @property · dunder methods · 10 min read
+

Python supports full object-oriented programming. Classes are blueprints; self refers to the instance. Dunder methods (double underscore) let you define how objects behave with operators.

Python — Classes
class NLPModel:
    # Class variable (shared by all instances)
    framework: str = "PyTorch"

    def __init__(self, name: str, layers: int):
        # Instance variables
        self.name   = name
        self.layers = layers
        self._trained = False   # convention: private

    def train(self, epochs: int = 10):
        print(f"Training {self.name} for {epochs} epochs...")
        self._trained = True

    @property
    def is_ready(self) -> bool:
        return self._trained

    def __repr__(self) -> str:
        return f"NLPModel(name='{self.name}', layers={self.layers})"

    def __len__(self) -> int:
        return self.layers


# Inheritance
class BERTModel(NLPModel):
    def __init__(self, name: str, layers: int, vocab_size: int):
        super().__init__(name, layers)    # call parent __init__
        self.vocab_size = vocab_size

    def train(self, epochs: int = 3):    # override
        print(f"Fine-tuning BERT: {self.name}")
        super().train(epochs)


model = NLPModel("TextClassifier", 6)
model.train()
print(model.is_ready)   # True  (property, no parentheses)
print(len(model))        # 6  (__len__)
print(model)             # NLPModel(name='TextClassifier', layers=6)
Tip: Use @dataclass decorator for simple data-holding classes — it auto-generates __init__, __repr__, and __eq__.
L05
File I/O & JSON
open() · with statement · json module · pathlib · 8 min read
+

Reading and writing files is fundamental for data science. Always use the with statement — it automatically closes the file even if an exception is raised.

Python — File I/O
# Writing a file
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("First line\n")
    f.writelines(["Second\n", "Third\n"])

# Reading all at once
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()         # entire file as string

# Reading line by line (memory-efficient for large files)
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

# Appending to a file
with open("data.txt", "a", encoding="utf-8") as f:
    f.write("Appended line\n")
Python — JSON & Pathlib
import json
from pathlib import Path

data = {
    "name": "Mikail",
    "scores": [95, 88, 92],
    "active": True
}

# Write JSON
with open("data.json", "w") as f:
    json.dump(data, f, indent=2, ensure_ascii=False)

# Read JSON
with open("data.json") as f:
    loaded = json.load(f)

# String ↔ JSON
json_str = json.dumps(data)      # dict → string
obj      = json.loads(json_str)  # string → dict

# pathlib — modern, object-oriented file paths
p = Path("data") / "corpus" / "texts.txt"
p.parent.mkdir(parents=True, exist_ok=True)  # create dirs
p.write_text("sample text", encoding="utf-8")
content = p.read_text(encoding="utf-8")

# List all .txt files recursively
txt_files = list(Path(".").rglob("*.txt"))
Encoding: Always specify encoding="utf-8" when working with Turkish or non-ASCII text — especially important for NLP corpora.
L06
Virtual Environments & pip
venv · pip · requirements.txt · best practices · 6 min read
+

Every Python project should have its own virtual environment. This isolates dependencies so different projects don't interfere with each other — critical for reproducible ML experiments.

Bash — venv setup
# Create virtual environment
python3 -m venv venv

# Activate (Linux / macOS)
source venv/bin/activate

# Activate (Windows)
venv\Scripts\activate

# Install packages
pip install numpy pandas torch transformers

# Save current packages to file
pip freeze > requirements.txt

# Install from requirements file (reproducible)
pip install -r requirements.txt

# Deactivate
deactivate

# Upgrade pip itself
pip install --upgrade pip
requirements.txt — example
numpy==1.26.4
pandas==2.2.1
torch==2.2.1
transformers==4.39.3
scikit-learn==1.4.1
beautifulsoup4==4.12.3
requests==2.31.0
Best practice: Add venv/ to your .gitignore — never commit virtual environments. Commit only requirements.txt.
