01
CONCEPT HIERARCHY

AI is a broad field. Everything nests inside it like Russian dolls. Understanding what contains what is the first step.

Artificial Intelligence (AI)
Any system that mimics human intelligence — reasoning, planning, learning, perception.
Includes: rule-based systems, expert systems, search algorithms, ML, DL, NLP, robotics
Machine Learning (ML)
Systems that learn patterns from data instead of being explicitly programmed. The core of modern AI.
Methods: Linear Regression, SVM, Decision Trees, Random Forest, K-Means
Deep Learning (DL)
ML with multi-layered neural networks. Learns hierarchical features automatically from raw data.
Architectures: CNN, RNN, LSTM, GAN, Transformer, Autoencoder
Natural Language Processing (NLP)
Applying ML/DL to human language — understanding, generating, translating, and classifying text.
Models: BERT, GPT, RoBERTa, T5 — Tasks: sentiment, NER, translation, QA
Computer Vision (CV)
Applying DL to images and video — detection, segmentation, recognition, generation.
Models: ResNet, YOLO, U-Net, ViT — Tasks: classification, object detection, OCR
02
GLOSSARY

Key terms you'll see repeatedly. Each card = one concept. Bold names link to tutorials where available.

Neural Network
NN
A computing system inspired by biological neurons. Input → hidden layers → output. The building block of deep learning.
→ Deep Learning, Perceptron, Backpropagation
Convolutional Neural Network
CNN
A neural network with convolutional layers that detect spatial patterns — edges, textures, shapes. Dominant in image tasks.
→ Computer Vision, Filters, Pooling
Recurrent Neural Network
RNN
A neural network with memory — each step feeds into the next. Built for sequential data like text or time series.
→ LSTM, GRU, Seq2Seq, Vanishing Gradient
Long Short-Term Memory
LSTM
An advanced RNN with gates (forget, input, output) that can learn long-range dependencies without vanishing gradients.
→ RNN, GRU, Sequence Modeling
Transformer
—
Architecture using self-attention instead of recurrence. Processes all tokens in parallel. Powers BERT, GPT, and modern LLMs.
→ Attention, BERT, GPT, Positional Encoding
Attention Mechanism
—
A method that lets a model "focus" on relevant parts of the input. Self-attention compares every token to every other token.
→ Transformer, Multi-Head Attention, Q/K/V
BERT
Bidirectional Encoder Representations from Transformers
A pre-trained language model that reads text in both directions. Fine-tuned for classification, NER, QA, and more.
→ Transformer, Masked Language Model, Fine-Tuning
GPT
Generative Pre-trained Transformer
An autoregressive language model — predicts the next token. Trained on massive text data. Powers ChatGPT and similar systems.
→ Transformer, Autoregressive, LLM
Large Language Model
LLM
A model with billions of parameters trained on internet-scale text. Can generate, translate, summarize, and reason about language.
→ GPT, BERT, Fine-Tuning, LoRA, RLHF
Fine-Tuning
—
Taking a pre-trained model and training it further on a specific dataset for a specific task. Much cheaper than training from scratch.
→ Transfer Learning, LoRA, PEFT
Backpropagation
Backprop
The algorithm that calculates how much each weight contributed to the error, then adjusts weights to reduce it. How neural networks learn.
→ Gradient Descent, Loss Function, Chain Rule
Gradient Descent
GD / SGD / Adam
An optimization algorithm — repeatedly steps in the direction that reduces the loss function. Variants: SGD, Adam, RMSprop.
→ Learning Rate, Loss Function, Optimizer
Overfitting
—
When a model memorizes training data but fails on new data. The gap between train accuracy and test accuracy is the signal.
→ Regularization, Dropout, Cross-Validation
Tokenization
—
Breaking text into smaller pieces (tokens) — words, subwords, or characters. The first step in any NLP pipeline.
→ BPE, WordPiece, SentencePiece, Vocabulary
Embedding
—
Converting words/tokens into dense numerical vectors. Similar meanings → similar vectors. The foundation of modern NLP.
→ Word2Vec, GloVe, BERT Embeddings
Epoch / Batch / Iteration
—
Epoch = one full pass through the dataset. Batch = subset processed together. Iteration = one weight update. 1000 samples, batch 100 = 10 iterations per epoch.
→ Training Loop, Batch Size, Mini-Batch
03
TOOLS & LIBRARIES

The ecosystem you'll work with. Each tool has a specific role — don't try to learn all of them at once. Follow the roadmap at the bottom.

Python
Language
The default language for AI/ML. 90%+ of tutorials, papers, and production code use Python.
Language
NumPy
Library
N-dimensional arrays and math operations. The foundation under every other data library.
Library
Pandas
Library
DataFrames for tabular data. Loading, cleaning, filtering, grouping — the data wrangling workhorse.
Library
Matplotlib / Seaborn
Library
Plotting and visualization. Matplotlib is flexible, Seaborn adds beautiful statistical charts on top.
Library
Scikit-Learn
Library
Classical ML: regression, classification, clustering, pipelines, cross-validation. Your first ML library.
Library
PyTorch
Framework
Deep learning framework by Meta. Dynamic computation graphs, intuitive API. The research standard.
Framework
TensorFlow / Keras
Framework
Deep learning framework by Google. Keras provides a high-level API. Strong in production and mobile deployment.
Framework
HuggingFace
Platform + Library
Hub for pre-trained models (BERT, GPT, etc.) + Transformers library. The npm of NLP.
LibraryPlatform
Jupyter Notebook
Tool
Interactive coding environment. Write code, see output, add notes — all in one document. Essential for data exploration.
Tool
Google Colab
Tool
Free cloud Jupyter with GPU access. No setup needed — open a browser and start training models.
Tool
SQL
Language
Query language for databases. Essential for extracting and preparing data before any ML pipeline.
Language
Git
Tool
Version control. Track changes, collaborate, roll back mistakes. Every project needs Git.
Tool

05
LEARNING ROADMAP

Follow this order. Each step builds on the previous one. Don't skip the math.

1
Python Core
Variables, functions, OOP, file handling, virtual environments. You need fluent Python before anything else.
Tools: Python 3.x, pip, venv
Start Python →
2
Math Foundations
Linear algebra (vectors, matrices, eigenvalues), probability, statistics. Then calculus — derivatives, gradients, optimization. This is what makes ML work.
Tools: NumPy, pen & paper
Start Math →
3
Data Tools
Learn to load, clean, explore, and visualize data. Pandas for tabular data, NumPy for arrays, Matplotlib for charts. 80% of ML time is spent on data.
Tools: Pandas, NumPy, Matplotlib, Jupyter
Start Pandas →
4
Classical Machine Learning
Linear/logistic regression, SVM, decision trees, random forest, k-means. Understand bias-variance tradeoff, cross-validation, evaluation metrics.
Tools: Scikit-Learn, Pandas
Start ML Theory →
5
Deep Learning
Neural networks, backpropagation, CNNs, optimization (Adam, dropout, batch norm). Build and train models with PyTorch.
Tools: PyTorch, Google Colab
Start Deep Learning →
6
Sequence Models (RNN/LSTM)
Recurrent networks for sequential data — text, time series. LSTM gates, bidirectional models, Seq2Seq. The bridge to NLP.
Tools: PyTorch
Start RNN →
7
NLP & Transformers
Tokenization, embeddings, attention mechanism, BERT, GPT, fine-tuning. The current state of the art in language AI.
Tools: HuggingFace Transformers, PyTorch
Start Transformers →
