CALCULUS

Limitler, türevler, integraller ve seriler — matematiğin en temel yapı taşları. Her mühendislik dalının ve her bilimsel modelin altında yatan saf matematik. Formül ağırlıklı, adım adım çözümlerle.

8 Lessons
Beginner → Intermediate
Prerequisites: Basic Algebra
L01
Limitler
Limit tanımı · limit kuralları · belirsizlik · L'Hôpital kuralı · 10 min
+

Bir fonksiyonun belirli bir noktaya yaklaşırken aldığı değer, o noktadaki limittir. Fonksiyon o noktada tanımlı olmasa bile limit var olabilir — bu, türevin ve integralin temelidir.

Tanım lim[x→a] f(x) = L

x, a'ya yaklaştıkça f(x) değeri L'ye yaklaşır.
Örnek: lim[x→2] (x² − 4)/(x − 2) = lim[x→2] (x+2)(x−2)/(x−2) = lim[x→2] (x+2) = 4
Temel Limit Kuralları lim[x→a] [f(x) ± g(x)] = lim f(x) ± lim g(x)
lim[x→a] [f(x) · g(x)] = lim f(x) · lim g(x)
lim[x→a] [f(x) / g(x)] = lim f(x) / lim g(x)   (lim g(x) ≠ 0)
lim[x→a] [f(x)]ⁿ = [lim f(x)]ⁿ
Önemli Limitler lim[x→0] sin(x)/x = 1
lim[x→0] (1 − cos(x))/x = 0
lim[x→∞] (1 + 1/x)ˣ = e ≈ 2.71828
lim[x→0] (eˣ − 1)/x = 1
★ L'Hôpital Kuralı (0/0 veya ∞/∞ durumları) lim[x→a] f(x)/g(x) belirsiz ise → lim[x→a] f'(x)/g'(x)

Örnek: lim[x→0] sin(x)/x → 0/0 belirsiz
L'Hôpital: lim[x→0] cos(x)/1 = 1 ✓

Örnek: lim[x→∞] ln(x)/x → ∞/∞ belirsiz
L'Hôpital: lim[x→∞] (1/x)/1 = 0
Dikkat: L'Hôpital kuralı sadece 0/0 veya ∞/∞ belirsizliğinde uygulanır. Diğer belirsizlikler (0·∞, ∞−∞, 0⁰, 1^∞, ∞⁰) önce bu forma dönüştürülmelidir.
L02
Türev Temelleri
Limit tanımı · güç kuralı · çarpım/bölüm · trigonometrik · üstel · 12 min
+

Türev, bir fonksiyonun anlık değişim hızıdır — eğrinin belirli bir noktasındaki teğet doğrusunun eğimi. Fizikten ekonomiye, mühendislikten yapay zekaya kadar her alanda kullanılır.

Tanım (Limitten) f'(x) = lim[h→0] (f(x+h) − f(x)) / h

Örnek: f(x) = x² için:
f'(x) = lim[h→0] ((x+h)² − x²)/h = lim[h→0] (2xh + h²)/h = lim[h→0] (2x + h) = 2x
f(x) = c (sabit)f'(x) = 0
f(x) = xⁿf'(x) = nxⁿ⁻¹
f(x) = eˣf'(x) = eˣ
f(x) = aˣf'(x) = aˣ · ln(a)
f(x) = ln(x)f'(x) = 1/x
f(x) = log_a(x)f'(x) = 1/(x · ln(a))
f(x) = sin(x)f'(x) = cos(x)
f(x) = cos(x)f'(x) = −sin(x)
f(x) = tan(x)f'(x) = sec²(x) = 1/cos²(x)
f(x) = √xf'(x) = 1/(2√x)
Çarpım & Bölüm Kuralı Çarpım: (f · g)' = f' · g + f · g'
Örnek: (x² · sin(x))' = 2x · sin(x) + x² · cos(x)

Bölüm: (f / g)' = (f' · g − f · g') / g²
Örnek: (sin(x)/x)' = (cos(x) · x − sin(x) · 1) / x² = (x·cos(x) − sin(x)) / x²
Neden eˣ özeldir? eˣ fonksiyonu türevi kendisine eşit olan tek fonksiyondur (sabit çarpan hariç). Bu özellik onu diferansiyel denklemlerde, olasılık dağılımlarında ve sinir ağlarının aktivasyon fonksiyonlarında vazgeçilmez kılar.
L03
Zincir Kuralı & İleri Türev
Chain rule · implicit türev · logaritmik türev · yüksek mertebe türev · 10 min
+

Zincir kuralı, bileşke fonksiyonların türevini alma yöntemidir. İç içe geçmiş fonksiyonları dıştan içe doğru türev alarak çözeriz.

Zincir Kuralı (Chain Rule) [f(g(x))]' = f'(g(x)) · g'(x)

"Dışın türevi × İçin türevi"

Örnek 1: d/dx [sin(3x²)] = cos(3x²) · 6x
Örnek 2: d/dx [e^(x³)] = e^(x³) · 3x²
Örnek 3: d/dx [ln(x² + 1)] = 1/(x² + 1) · 2x = 2x/(x² + 1)
Örnek 4: d/dx [(2x + 5)⁷] = 7(2x + 5)⁶ · 2 = 14(2x + 5)⁶
İmplicit (Kapalı) Türev y açıkça x cinsinden yazılamadığında, her iki tarafın türevini alırız ve y' için çözeriz.

Örnek: x² + y² = 25 (çember denklemi)
2x + 2y · y' = 0
y' = −x/y
Logaritmik Türev Karmaşık çarpım/bölüm/üs ifadelerinde: önce ln al, sonra türev al.

Örnek: y = xˣ
ln(y) = x · ln(x)
y'/y = ln(x) + 1
y' = xˣ(ln(x) + 1)
Yüksek Mertebe Türevler f''(x) = d²f/dx²   (ikinci türev — ivme, büküm)
f'''(x) = d³f/dx³

Örnek: f(x) = x⁴ → f'(x) = 4x³ → f''(x) = 12x² → f'''(x) = 24x
Çoklu zincir: d/dx [sin(e^(x²))] = cos(e^(x²)) · e^(x²) · 2x — üç katman, her biri dıştan içe.
L04
Türev Uygulamaları
Ekstremum · büküm noktası · grafik çizimi · optimizasyon problemleri · 12 min
+

Türevin en güçlü uygulaması optimizasyondur — fonksiyonun en büyük ve en küçük değerlerini bulmak. Birinci türev kritik noktaları, ikinci türev bunların maksimum mu minimum mu olduğunu belirler.

Kritik Nokta & Ekstremum Kritik nokta: f'(c) = 0 veya f'(c) tanımsız

Birinci türev testi:
f' işaret değiştiriyorsa: + → − ise yerel maksimum
f' işaret değiştiriyorsa: − → + ise yerel minimum

İkinci türev testi:
f'(c) = 0 ve f''(c) < 0 → yerel maksimum
f'(c) = 0 ve f''(c) > 0 → yerel minimum
f'(c) = 0 ve f''(c) = 0 → test belirsiz, birinci türev testine başvur
Büküm Noktası (Inflection Point) f''(x) = 0 ve f'' işaret değiştiriyorsa → büküm noktası
Büküm noktasında eğri konkavdan konvekse (veya tersi) geçer.

Örnek: f(x) = x³
f'(x) = 3x², f''(x) = 6x
f''(0) = 0 ve f'' işaret değiştiriyor → x = 0 büküm noktası
★ Optimizasyon Problemi Problem: Çevresi 20 cm olan dikdörtgenin en büyük alanını bulun.

Çevre: 2x + 2y = 20 → y = 10 − x
Alan: A(x) = x · y = x(10 − x) = 10x − x²
A'(x) = 10 − 2x = 0 → x = 5
A''(5) = −2 < 0 → maksimum ✓
y = 10 − 5 = 5 → Kare! Alan = 25 cm²
Grafik çizim algoritması: 1) Tanım kümesini belirle. 2) f'(x) = 0 → kritik noktalar. 3) f''(x) = 0 → büküm noktaları. 4) Artan/azalan aralıklar (f' işareti). 5) Konkav/konveks aralıklar (f'' işareti). 6) Sınır davranışı (x → ±∞).
L05
Belirsiz İntegral
Antitürev · temel formüller · yerine koyma · kısmi integrasyon · 12 min
+

Belirsiz integral (antitürev), türev işleminin tersidir. F'(x) = f(x) ise, ∫f(x)dx = F(x) + C'dir. Burada C, integrasyon sabitidir.

∫ xⁿ dxxⁿ⁺¹/(n+1) + C   (n ≠ −1)
∫ 1/x dxln|x| + C
∫ eˣ dxeˣ + C
∫ aˣ dxaˣ/ln(a) + C
∫ sin(x) dx−cos(x) + C
∫ cos(x) dxsin(x) + C
∫ sec²(x) dxtan(x) + C
∫ 1/(1+x²) dxarctan(x) + C
∫ 1/√(1−x²) dxarcsin(x) + C
★ Yerine Koyma (u-substitution) ∫ f(g(x)) · g'(x) dx → u = g(x), du = g'(x) dx → ∫ f(u) du

Örnek: ∫ 2x · cos(x²) dx
u = x², du = 2x dx
= ∫ cos(u) du = sin(u) + C = sin(x²) + C

Örnek: ∫ e^(3x) dx
u = 3x, du = 3 dx → dx = du/3
= (1/3) ∫ eᵘ du = (1/3)eᵘ + C = (1/3)e^(3x) + C
★ Kısmi İntegrasyon (Integration by Parts) ∫ u dv = uv − ∫ v du

LIATE kuralı (u seçim önceliği): Logaritmik → Inverse trig → Algebraic → Trigonometric → Exponential

Örnek: ∫ x · eˣ dx
u = x → du = dx
dv = eˣ dx → v = eˣ
= x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C = eˣ(x − 1) + C
Doğrulama: İntegral sonucunun doğruluğunu her zaman türev alarak kontrol edebilirsin. d/dx[eˣ(x−1)] = eˣ(x−1) + eˣ = eˣ·x − eˣ + eˣ = x·eˣ ✓
L06
Belirli İntegral
Riemann toplamı · Analizin Temel Teoremi · alan hesabı · 10 min
+

Belirli integral, bir fonksiyonun belirli bir aralıktaki eğri altı alanını hesaplar. Riemann toplamlarının limitidir ve Analizin Temel Teoremi ile antitürev kullanarak hesaplanır.

Analizin Temel Teoremi ∫ₐᵇ f(x) dx = F(b) − F(a)

F, f'nin herhangi bir antitürevidir.

Örnek: ∫₁³ x² dx = [x³/3]₁³ = 27/3 − 1/3 = 26/3 ≈ 8.667

Örnek: ∫₀^π sin(x) dx = [−cos(x)]₀^π = −cos(π) − (−cos(0)) = 1 + 1 = 2
Belirli İntegral Özellikleri ∫ₐᵃ f(x) dx = 0
∫ₐᵇ f(x) dx = −∫ᵇₐ f(x) dx
∫ₐᵇ [f(x) ± g(x)] dx = ∫ₐᵇ f(x) dx ± ∫ₐᵇ g(x) dx
∫ₐᵇ c · f(x) dx = c · ∫ₐᵇ f(x) dx
∫ₐᵇ f(x) dx = ∫ₐᶜ f(x) dx + ∫ᶜᵇ f(x) dx
★ İki Eğri Arası Alan A = ∫ₐᵇ |f(x) − g(x)| dx

Örnek: y = x² ve y = x arasındaki alan (0 ile 1 arası)
A = ∫₀¹ (x − x²) dx = [x²/2 − x³/3]₀¹ = 1/2 − 1/3 = 1/6
Dikkat: f(x) < 0 olan aralıklarda integral negatif çıkar. Alan hesabı için mutlak değer kullanılmalıdır: ∫|f(x)| dx.
L07
İntegral Uygulamaları
Dönel cisim hacmi · yay uzunluğu · improper integral · 10 min
+

İntegraller sadece alan hesabı değil — hacim, uzunluk, kütle merkezi ve daha birçok fiziksel büyüklüğü hesaplamak için kullanılır.

Dönel Cisim Hacmi — Disk Yöntemi V = π ∫ₐᵇ [f(x)]² dx

f(x) eğrisi x-ekseni etrafında döndürüldüğünde oluşan cismin hacmi.

Örnek: y = x², [0, 2] aralığında x-ekseni etrafında döndürülürse:
V = π ∫₀² (x²)² dx = π ∫₀² x⁴ dx = π [x⁵/5]₀² = π · 32/5 = 32π/5
Yay Uzunluğu L = ∫ₐᵇ √(1 + [f'(x)]²) dx

Örnek: y = x^(3/2), [0, 4] aralığında:
y' = (3/2)x^(1/2)
L = ∫₀⁴ √(1 + 9x/4) dx
★ Improper (Has Olmayan) İntegral Sonsuz sınırlı veya tanımsız noktaları olan integraller.

Örnek: ∫₁^∞ 1/x² dx = lim[b→∞] ∫₁ᵇ x⁻² dx = lim[b→∞] [−1/x]₁ᵇ = lim[b→∞] (−1/b + 1) = 1 (yakınsak)

Örnek: ∫₁^∞ 1/x dx = lim[b→∞] [ln|x|]₁ᵇ = lim[b→∞] ln(b) = ∞ (ıraksak)
p-serisi testi: ∫₁^∞ 1/xᵖ dx → p > 1 ise yakınsak, p ≤ 1 ise ıraksak. Bu kural seri yakınsamasında da temel bir araçtır.
L08
Seriler & Taylor Açılımı
Geometrik seri · yakınsama testleri · Taylor/Maclaurin · önemli açılımlar · 12 min
+

Sonsuz seriler, türev ve integralin bir adım ötesidir. Karmaşık fonksiyonları polinom toplamları olarak ifade etmek — hesaplamada, fizikte ve nümerik analizde temel bir araçtır.

Geometrik Seri Σ[n=0→∞] rⁿ = 1/(1−r)   |r| < 1 ise yakınsak

Örnek: 1 + 1/2 + 1/4 + 1/8 + ... = 1/(1 − 1/2) = 2
Yakınsama Testleri Oran testi: lim[n→∞] |aₙ₊₁/aₙ| = L → L < 1 yakınsak, L > 1 ıraksak
Kök testi: lim[n→∞] |aₙ|^(1/n) = L → aynı kural
Karşılaştırma: 0 ≤ aₙ ≤ bₙ → Σbₙ yakınsaksa Σaₙ de yakınsak
İntegral testi: Σf(n) ve ∫f(x)dx aynı davranışı gösterir
★ Taylor Serisi f(x) = Σ[n=0→∞] f⁽ⁿ⁾(a)/n! · (x − a)ⁿ

a = 0 için Maclaurin Serisi:
f(x) = f(0) + f'(0)·x + f''(0)·x²/2! + f'''(0)·x³/3! + ...
★ Önemli Maclaurin Açılımları eˣ = 1 + x + x²/2! + x³/3! + x⁴/4! + ...   (tüm x için)

sin(x) = x − x³/3! + x⁵/5! − x⁷/7! + ...   (tüm x için)

cos(x) = 1 − x²/2! + x⁴/4! − x⁶/6! + ...   (tüm x için)

ln(1+x) = x − x²/2 + x³/3 − x⁴/4 + ...   (−1 < x ≤ 1)

1/(1−x) = 1 + x + x² + x³ + ...   (|x| < 1)
Neden Taylor serisi önemli? Bilgisayarlar sin(x), eˣ, ln(x) gibi fonksiyonları doğrudan hesaplayamaz — Taylor polinomlarının sonlu terimlerini kullanarak yaklaşık değer hesaplar. Hesap makinenden yapay zekaya, tüm nümerik hesaplama bu temele dayanır.
