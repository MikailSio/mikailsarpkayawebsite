MATH
FOUNDATIONS

The mathematical language behind every ML algorithm. Derivatives drive gradient descent, integrals define probability distributions, linear algebra powers every neural network layer. No shortcuts — understand the math, understand the models.

7 Lessons
Beginner → Intermediate
Prerequisites: Basic Algebra
L01
Functions & Graphs
f(x) · domain/range · linear · polynomial · exponential · sigmoid · 8 min
+

A function maps each input to exactly one output: f(x) = y. In ML, everything is a function — a model maps inputs to predictions, a loss function maps predictions to error values, an activation function maps weighted sums to neuron outputs.

Key Functions in ML Linear: f(x) = wx + b — the building block of every neural network layer
Polynomial: f(x) = a₀ + a₁x + a₂x² + ... — models non-linear relationships
Exponential: f(x) = eˣ — appears in softmax, probability distributions
Sigmoid: σ(x) = 1 / (1 + e⁻ˣ) — maps any real number to (0, 1)
ReLU: f(x) = max(0, x) — the most popular activation function
Python — Visualizing Functions
import numpy as np

x = np.linspace(-5, 5, 100)

# Key ML functions
linear  = 2 * x + 1                      # y = 2x + 1
sigmoid = 1 / (1 + np.exp(-x))            # σ(x)
relu    = np.maximum(0, x)                  # max(0, x)
tanh    = np.tanh(x)                         # maps to (-1, 1)

# Domain: set of valid inputs
# Range: set of possible outputs
# sigmoid: domain=ℝ, range=(0,1)
# ReLU:    domain=ℝ, range=[0,∞)
# tanh:    domain=ℝ, range=(-1,1)

# Composition — f(g(x)) — this IS a neural network
def layer(x, w, b):
    return np.maximum(0, w * x + b)  # linear → ReLU

output = layer(layer(x, 0.5, 1), -0.3, 2)  # 2-layer network!
Key insight: A neural network is just a composition of functions: f₃(f₂(f₁(x))). Each layer applies a linear transformation (wx + b) followed by a non-linear activation. Understanding function composition = understanding neural networks.
L02
Derivatives — The Core of Learning
Limit definition · basic rules · chain rule · partial derivatives · 12 min
+

The derivative measures the rate of change of a function. In ML, the derivative tells us: "if I slightly change this parameter, how much does the loss change?" This is the entire basis of gradient descent — the algorithm that trains every neural network.

Definition f'(x) = lim[h→0] (f(x+h) − f(x)) / h

The derivative at a point gives the slope of the tangent line — the instantaneous rate of change.
Essential Rules Power rule: d/dx[xⁿ] = nxⁿ⁻¹
Constant: d/dx[c] = 0
Sum: d/dx[f + g] = f' + g'
Product: d/dx[fg] = f'g + fg'
Quotient: d/dx[f/g] = (f'g − fg') / g²
Exponential: d/dx[eˣ] = eˣ
Logarithm: d/dx[ln(x)] = 1/x
★ Chain Rule — The Heart of Backpropagation d/dx[f(g(x))] = f'(g(x)) · g'(x)

"Derivative of the outer × derivative of the inner"
Example: d/dx[sin(3x²)] = cos(3x²) · 6x
Python — Derivatives in Practice
import numpy as np

# Numerical derivative (approximation)
def numerical_derivative(f, x, h=1e-7):
    return (f(x + h) - f(x - h)) / (2 * h)

# Example: f(x) = x² → f'(x) = 2x
f = lambda x: x ** 2
print(numerical_derivative(f, 3))  # ≈ 6.0 (exact: 2×3 = 6)

# Sigmoid derivative: σ'(x) = σ(x)(1 − σ(x))
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    s = sigmoid(x)
    return s * (1 - s)

# ReLU derivative: 0 if x<0, 1 if x>0
def relu_derivative(x):
    return np.where(x > 0, 1, 0)

# MSE loss derivative: d/dŷ[(y − ŷ)²] = −2(y − ŷ)
y_true = np.array([1.0, 0.0, 1.0])
y_pred = np.array([0.9, 0.2, 0.8])
mse_grad = -2 * (y_true - y_pred)  # gradient of MSE
Why chain rule matters: Backpropagation IS the chain rule applied repeatedly. For a network f₃(f₂(f₁(x))), the gradient flows backward: ∂L/∂x = ∂L/∂f₃ · ∂f₃/∂f₂ · ∂f₂/∂f₁ · ∂f₁/∂x. Each "·" is one layer of the chain rule.
L03
Derivatives in ML — Gradient Descent
Gradient · partial derivatives · gradient descent step · learning rate · 10 min
+

The gradient is the vector of all partial derivatives — it points in the direction of steepest increase. To minimize a loss function, we move in the opposite direction of the gradient. This is gradient descent, and it's how every ML model learns.

Partial Derivatives & Gradient For f(x, y) = x² + 3xy + y²:
∂f/∂x = 2x + 3y   (treat y as constant)
∂f/∂y = 3x + 2y   (treat x as constant)

Gradient: ∇f = [∂f/∂x, ∂f/∂y] = [2x + 3y, 3x + 2y]
★ Gradient Descent Update Rule θ := θ − α · ∇J(θ)

θ = parameters (weights & biases)
α = learning rate (step size, typically 1e-3 to 1e-5)
∇J(θ) = gradient of loss w.r.t. parameters
Python — Gradient Descent from Scratch
import numpy as np

# Minimize f(x) = (x − 3)² + 2
# Derivative: f'(x) = 2(x − 3)
# Minimum at x = 3

x = 10.0          # start far from minimum
lr = 0.1          # learning rate

for step in range(20):
    gradient = 2 * (x - 3)       # f'(x)
    x = x - lr * gradient         # update step
    loss = (x - 3)**2 + 2
    if step % 5 == 0:
        print(f"Step {step:2d}: x={x:.4f}, loss={loss:.4f}")
# Step  0: x=8.6000, loss=33.3600
# Step  5: x=3.4096, loss=2.1678
# Step 10: x=3.0134, loss=2.0002
# Step 15: x=3.0004, loss=2.0000

# ★ 2D Gradient Descent (linear regression)
np.random.seed(42)
X = np.random.randn(100)
y = 3 * X + 7 + np.random.randn(100) * 0.5  # true: w=3, b=7

w, b = 0.0, 0.0   # random init
lr = 0.01

for epoch in range(200):
    y_pred = w * X + b
    loss = np.mean((y - y_pred) ** 2)
    dw = -2 * np.mean(X * (y - y_pred))    # ∂L/∂w
    db = -2 * np.mean(y - y_pred)           # ∂L/∂b
    w -= lr * dw
    b -= lr * db

print(f"Learned: w={w:.2f}, b={b:.2f}")  # ≈ w=3.0, b=7.0
Learning rate matters: Too large → overshoots minimum and diverges. Too small → converges extremely slowly. This is why lr scheduling (warmup, cosine decay) is so important in training transformers.
L04
Integrals — Area & Accumulation
Indefinite/definite integral · Fundamental Theorem · basic rules · 10 min
+

The integral is the reverse of differentiation — it accumulates quantities over an interval. If the derivative gives you speed, the integral gives you distance traveled. In ML, integrals define probability distributions, expected values, and continuous loss functions.

Indefinite Integral (Antiderivative) ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C   (n ≠ −1)
∫ eˣ dx = eˣ + C
∫ 1/x dx = ln|x| + C
∫ cos(x) dx = sin(x) + C
∫ sin(x) dx = −cos(x) + C
Definite Integral & Fundamental Theorem ∫ₐᵇ f(x) dx = F(b) − F(a)

where F is the antiderivative of f.
Example: ∫₀² x² dx = [x³/3]₀² = 8/3 − 0 = 8/3 ≈ 2.667

Geometrically: the area under the curve f(x) from a to b.
Python — Numerical Integration
import numpy as np
from scipy import integrate

# Analytical: ∫₀² x² dx = 8/3
result, error = integrate.quad(lambda x: x**2, 0, 2)
print(f"∫₀² x² dx = {result:.4f}")  # 2.6667

# Trapezoidal rule (manual, no scipy)
x = np.linspace(0, 2, 1000)
y = x ** 2
area = np.trapz(y, x)
print(f"Trapezoid: {area:.4f}")      # 2.6667

# ★ Probability: P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx
# Normal distribution PDF
def normal_pdf(x, mu=0, sigma=1):
    return (1 / (sigma * np.sqrt(2 * np.pi))) * \
           np.exp(-0.5 * ((x - mu) / sigma) ** 2)

# P(-1 ≤ X ≤ 1) for standard normal
prob, _ = integrate.quad(normal_pdf, -1, 1)
print(f"P(-1 ≤ X ≤ 1) = {prob:.4f}")  # 0.6827 (68.27%)
ML Connection: The area under the ROC curve (AUC-ROC) is literally an integral. Probability density functions must integrate to 1 over their entire domain. Cross-entropy loss involves log-probabilities which relate to integrals of information.
L05
Integrals in ML — Expectation & Probability
PDF · CDF · expected value · variance · KL divergence · 10 min
+

In machine learning, integrals appear everywhere through probability. The expected value of a loss function, the area under precision-recall curves, KL divergence between distributions — all defined by integrals.

Expected Value & Variance Expected value: E[X] = ∫ x · f(x) dx — the "average" outcome
Variance: Var(X) = E[X²] − (E[X])² — how spread out the values are
Standard deviation: σ = √Var(X)
★ KL Divergence (used in VAEs, knowledge distillation) D_KL(P ∥ Q) = ∫ P(x) · ln(P(x) / Q(x)) dx

Measures how much distribution P differs from Q.
D_KL ≥ 0, and D_KL = 0 only when P = Q.
Python — Expectation & KL Divergence
import numpy as np
from scipy import stats

# Expected value of a normal distribution
dist = stats.norm(loc=5, scale=2)  # μ=5, σ=2
print(f"E[X] = {dist.mean()}")         # 5.0
print(f"Var(X) = {dist.var()}")        # 4.0

# CDF: P(X ≤ x) — cumulative distribution function
print(f"P(X ≤ 5) = {dist.cdf(5):.4f}")   # 0.5000
print(f"P(X ≤ 7) = {dist.cdf(7):.4f}")   # 0.8413

# ★ KL Divergence between two distributions
def kl_divergence(p, q):
    """Discrete KL divergence."""
    p = np.array(p, dtype=np.float64)
    q = np.array(q, dtype=np.float64)
    return np.sum(p * np.log(p / q + 1e-10))

p = [0.4, 0.3, 0.3]   # true distribution
q = [0.33, 0.33, 0.34] # predicted (uniform-ish)
print(f"KL(P||Q) = {kl_divergence(p, q):.4f}")  # 0.0139

# Cross-entropy loss = entropy + KL divergence
# H(P, Q) = −Σ P(x) log Q(x) = H(P) + D_KL(P||Q)
Why this matters: Cross-entropy loss (the standard classification loss) is directly related to KL divergence. When you minimize cross-entropy, you're minimizing the distance between your model's predicted distribution and the true distribution.
L06
Linear Algebra Essentials
Vectors · matrices · dot product · matrix multiplication · eigenvalues · 12 min
+

Linear algebra is the computational engine of deep learning. Every input is a vector, every weight matrix transforms that vector, every attention score is a dot product. Without linear algebra, there is no deep learning.

Core Operations Dot product: a · b = Σ aᵢbᵢ = |a||b|cos(θ) — measures similarity
Matrix × vector: y = Wx + b — a single neural network layer
Matrix × matrix: C = AB where Cᵢⱼ = Σₖ AᵢₖBₖⱼ — batch processing
Transpose: (Aᵀ)ᵢⱼ = Aⱼᵢ — swap rows and columns
Norm: ‖x‖ = √(Σ xᵢ²) — vector length, used in regularization
★ In Neural Networks Forward pass: h = σ(Wx + b) — one layer
Attention: scores = QKᵀ / √dₖ — scaled dot-product attention
Embedding lookup: e = E[token_id] — row selection from matrix
Batch processing: Y = XW + B — entire batch at once
Python — Linear Algebra for DL
import numpy as np

# Dot product — cosine similarity for embeddings
e1 = np.array([0.2, 0.8, 0.1])  # embedding of "king"
e2 = np.array([0.3, 0.7, 0.2])  # embedding of "queen"
similarity = np.dot(e1, e2) / (np.linalg.norm(e1) * np.linalg.norm(e2))
print(f"Cosine similarity: {similarity:.4f}")  # 0.9878

# ★ Single neural network layer
X = np.random.randn(32, 768)    # batch of 32, dim 768
W = np.random.randn(768, 256)   # weights
b = np.zeros(256)               # bias

h = X @ W + b                    # linear: (32, 256)
h = np.maximum(0, h)             # ReLU activation

# ★ Simplified self-attention
seq_len, d_model = 10, 64
Q = np.random.randn(seq_len, d_model)  # queries
K = np.random.randn(seq_len, d_model)  # keys
V = np.random.randn(seq_len, d_model)  # values

scores = Q @ K.T / np.sqrt(d_model)    # (10, 10)
# Apply softmax row-wise → attention weights
exp_s = np.exp(scores - scores.max(axis=-1, keepdims=True))
attn = exp_s / exp_s.sum(axis=-1, keepdims=True)
output = attn @ V                       # (10, 64)
Eigenvalues & SVD: PCA (dimensionality reduction) uses eigendecomposition. SVD is used in LSA (Latent Semantic Analysis) for topic modeling, and in LoRA for efficient fine-tuning. These are advanced but incredibly useful tools.
L07
Probability & Statistics for ML
Bayes' theorem · distributions · MLE · bias-variance tradeoff · 12 min
+

Probability is the language of uncertainty, and ML is all about making decisions under uncertainty. Bayes' theorem is the foundation of many classifiers, maximum likelihood estimation (MLE) is how models learn parameters, and understanding distributions tells you which loss function to use.

Bayes' Theorem P(A|B) = P(B|A) · P(A) / P(B)

In NLP classification:
P(spam | "free money") = P("free money" | spam) · P(spam) / P("free money")

posterior = likelihood × prior / evidence
Key Distributions Bernoulli: P(X=1) = p — binary classification output
Categorical: P(X=k) = pₖ — multi-class (softmax output)
Gaussian: f(x) = (1/σ√2π) e^(−(x−μ)²/2σ²) — weight initialization, noise
Uniform: f(x) = 1/(b−a) — random sampling, Xavier init
★ Maximum Likelihood Estimation θ̂ = argmax[θ] Π P(xᵢ | θ)

In practice, we minimize negative log-likelihood:
θ̂ = argmin[θ] −Σ log P(xᵢ | θ)

Cross-entropy loss IS negative log-likelihood for classification!
Python — Probability in Practice
import numpy as np
from scipy import stats

# Naive Bayes — Bayes' theorem in action
# P(spam|word) ∝ P(word|spam) × P(spam)
p_spam = 0.3                       # prior
p_word_given_spam = 0.8             # likelihood
p_word_given_ham = 0.1              # likelihood
p_word = p_word_given_spam * p_spam + p_word_given_ham * (1 - p_spam)

posterior = (p_word_given_spam * p_spam) / p_word
print(f"P(spam|word) = {posterior:.4f}")  # 0.7742

# ★ Cross-entropy = negative log-likelihood
y_true = np.array([1, 0, 1, 1, 0])            # true labels
y_pred = np.array([0.9, 0.2, 0.8, 0.7, 0.1])  # predicted probs

ce_loss = -np.mean(
    y_true * np.log(y_pred + 1e-8) +
    (1 - y_true) * np.log(1 - y_pred + 1e-8)
)
print(f"Cross-entropy: {ce_loss:.4f}")  # 0.2271

# Gaussian distribution — weight initialization
weights = np.random.normal(loc=0, scale=0.02, size=(768, 768))
print(f"Mean: {weights.mean():.4f}, Std: {weights.std():.4f}")
Bias-Variance Tradeoff: High bias = underfitting (model too simple). High variance = overfitting (model memorizes training data). The goal is finding the sweet spot. Regularization (L1/L2, dropout) reduces variance at the cost of slightly more bias.
