L01
DataFrame & Series Basics
pd.DataFrame · pd.Series · dtypes · shape · info() · describe() · head/tail · value_counts · memory_usage
+

A DataFrame is a 2D labeled table — think of it as a spreadsheet in Python. A Series is a single column. Together, they are the core data structures you'll use for every data task, from loading CSVs to feeding NLP models.

L02
Indexing & Selection
loc · iloc · boolean indexing · query() · isin() · at/iat · between()
+

Selecting the right rows and columns is the most frequent Pandas operation. loc uses labels, iloc uses integer positions, and boolean indexing lets you filter with conditions — essential for splitting datasets and extracting subsets.

loc & iloc

Python
# loc — label-based selection
print(df.loc[0, "text"])                # single value
print(df.loc[0:2, ["text", "label"]])   # rows 0-2, specific cols
print(df.loc[:, "score"])               # all rows, one column

# iloc — integer position-based
print(df.iloc[0])                       # first row (Series)
print(df.iloc[0:2, 0:2])               # first 2 rows, first 2 cols
print(df.iloc[-1])                      # last row

# at/iat — fast scalar access (single cell)
print(df.at[0, "text"])     # faster than loc for single values
print(df.iat[0, 0])         # by position
Output: 
Great movie
             text  label
0     Great movie      1
1   Terrible film      0
2    Average show      0

Boolean Indexing & query()

Python
# Boolean indexing — filtering with conditions
positive = df[df["label"] == 1]
print("Positive:\n", positive)

high_conf = df[df["score"] > 0.9]
print("High confidence:\n", high_conf)

# Multiple conditions (use & for AND, | for OR)
subset = df[(df["label"] == 1) & (df["score"] > 0.8)]

# query() — cleaner syntax for complex filters
result = df.query("label == 1 and score > 0.8")
print("Query result:\n", result)

# isin — filter by list of values
keep = df[df["label"].isin([0, 1])]

# between — range filter
mid_score = df[df["score"].between(0.3, 0.8)]
print("Mid scores:\n", mid_score)
Output: 
Positive:
           text  label  score
0   Great movie      1   0.95
3      Loved it      1   0.91

High confidence:
           text  label  score
0   Great movie      1   0.95
3      Loved it      1   0.91

Query result:
           text  label  score
0   Great movie      1   0.95
3      Loved it      1   0.91

Mid scores:
            text  label  score
2   Average show      0   0.48
Common mistake: df["label"] == 1 & df["score"] > 0.8 fails due to operator precedence. Always wrap conditions in parentheses: (df["label"] == 1) & (df["score"] > 0.8).
L03
Data Cleaning
isnull · dropna · fillna · duplicated · drop_duplicates · replace · astype · rename · clip
+

80% of data science is cleaning data. Missing values, duplicates, wrong types, inconsistent strings — Pandas gives you the tools to handle all of it. In NLP, cleaning means the difference between a good model and garbage output.

Missing Values

Python
# Create sample with missing values
df = pd.DataFrame({
    "text":  ["Good", None, "Great", "Bad", ""],
    "label": [1, 0, np.nan, 0, 1],

# Detect missing values
print("Null counts:\n", df.isnull().sum())

# dropna — remove rows with NaN
print("Drop all NaN:", len(df.dropna()), "rows")
print("Drop if text NaN:", len(df.dropna(subset=["text"])), "rows")

# fillna — replace NaN with value
df["score"] = df["score"].fillna(0.0)
df["label"] = df["label"].fillna(-1)

# Fill with column-specific values
df = df.fillna({"score": 0, "label": -1, "text": ""})

Duplicates, Types & Rename

Python
# Duplicates
print("Duplicate rows:", df.duplicated().sum())
df = df.drop_duplicates()
df = df.drop_duplicates(subset=["text"], keep="first")

# Type conversion
df["label"] = df["label"].astype(int)
df["score"] = pd.to_numeric(df["score"], errors="coerce")  # invalid → NaN

# Rename columns
df = df.rename(columns={"text": "content", "label": "sentiment"})
print(df.columns.tolist())

# Replace values
df["sentiment"] = df["sentiment"].replace({0: "negative", 1: "positive"})

# clip — limit numeric values to a range
df["score"] = df["score"].clip(0, 1)

# String cleaning chain (NLP essential)
df["content"] = (
    df["content"]
    .str.strip()
    .str.lower()
    .str.replace(r"\s+", " ", regex=True)
)

# Remove rows where text is too short
df = df[df["content"].str.len() > 2]

Duplicate rows: 0
['content', 'sentiment', 'score']

GroupBy & Aggregation
groupby · agg · transform · apply · pivot_table · crosstab · value_counts
+

GroupBy is the split-apply-combine pattern: split data into groups, apply a function, combine results. It's how you compute per-class statistics, per-category counts, and aggregate metrics — fundamental for EDA before training any model.

Python
df = pd.DataFrame({
    "category": ["tech", "sports", "tech", "sports", "tech"],
    "text": ["AI news", "Match result", "GPU release", "Transfer", "LLM paper"],
    "word_count": [150, 200, 180, 90, 320],
    "score": [0.92, 0.78, 0.88, 0.65, 0.95]
})

# Basic groupby
print("Mean score per category:")
print(df.groupby("category")["score"].mean())

L05
Merge, Join & Concat
merge (inner/outer/left/right) · concat · ignore_index · suffixes · indicator
+

Real-world data lives in multiple tables. merge combines DataFrames on shared keys (like SQL JOINs), concat stacks them vertically or horizontally. You'll use these constantly when combining scraped data from different sources or adding metadata to your corpus.

Python
texts = pd.DataFrame({
    "id": [1, 2, 3, 4],
    "text": ["Great product", "Bad quality", "Nice design", "Poor service"]
})
labels = pd.DataFrame({
    "id": [1, 2, 3, 5],
    "sentiment": ["pos", "neg", "pos", "neg"]
})

# inner — only matching IDs
inner = texts.merge(labels, on="id", how="inner")
print("Inner:\n", inner)

# left — keep all from left, NaN for unmatched
left = texts.merge(labels, on="id", how="left")
print("Left:\n", left)

# outer — keep everything
outer = texts.merge(labels, on="id", how="outer")
print("Outer:\n", outer)

# indicator — shows merge source
check = texts.merge(labels, on="id", how="outer", indicator=True)
print("Indicator:\n", check["_merge"].value_counts())

L06
String & Text Operations
str accessor · contains · extract · findall · replace · split · len · NLP preprocessing
+

Pandas' .str accessor lets you apply string operations to entire columns at once — no loops needed. Combined with regex, it becomes a powerful vectorized text preprocessing engine for NLP.

Python
df = pd.DataFrame({
    "text": [
        "  Visit https://t.co/abc for INFO!  ",
        "RT @user: Great news about #NLP",
        "Check email: test@mail.com ASAP",
        "Türkçe İçerik: Güzel bir HABER"
    ]
})

# Vectorized cleaning chain (no loops!)
df["clean"] = (
    df["text"]
    .str.strip()
    .str.lower()
    .str.replace(r"https?://\S+", "", regex=True)
    .str.replace(r"@\w+", "", regex=True)
    .str.replace(r"#(\w+)", r"\1", regex=True)
    .str.replace(r"[\w.+-]+@[\w-]+\.[\w.]+", "", regex=True)
    .str.replace(r"\s+", " ", regex=True)
    .str.strip()
)
print(df[["text", "clean"]].to_string())
Output: 
                                    text                          clean
0  Visit https://t.co/abc for INFO!       visit for info!
1  RT @user: Great news about #NLP        rt : great news about nlp
2  Check email: test@mail.com ASAP        check email: asap

L09
Performance & Best Practices
vectorized ops vs loops · category dtype · memory optimization · eval/query · pipe · method chaining
+

Pandas can be slow if you use it wrong. The golden rule: never loop over rows. Use vectorized operations, choose the right dtypes, and learn when to use eval() and query() for large DataFrames.

Vectorize Everything

Python
# ❌ SLOW — iterating row by row (~45s on 1M rows)
for i, row in df.iterrows():
    df.at[i, "word_count"] = len(row["text"].split())

# ✅ FAST — vectorized (~0.2s on 1M rows, 225x faster)
df["word_count"] = df["text"].str.split().str.len()

# ❌ SLOW — apply with lambda
df["upper"] = df["text"].apply(lambda x: x.upper())

# ✅ FAST — built-in vectorized method
df["upper"] = df["text"].str.upper()

# ✅ eval() — fast expression evaluation for large DataFrames
df.eval("ratio = score / word_count", inplace=True)

# ✅ query() — faster than boolean indexing for large DFs
result = df.query("score > 0.8 and word_count > 50")

Memory Optimization

Python
# Check memory usage
print(df.memory_usage(deep=True).sum() / 1024**2, "MB")

# category dtype — for columns with few unique values
print("Before:", df["label"].memory_usage(deep=True), "bytes")
df["label"] = df["label"].astype("category")
print("After: ", df["label"].memory_usage(deep=True), "bytes")

# Downcast numeric types
df["count"] = pd.to_numeric(df["count"], downcast="integer")
df["score"] = pd.to_numeric(df["score"], downcast="float")

# ★ Method chaining with .pipe()
def remove_short(df, min_words=10):
    return df[df["text"].str.split().str.len() >= min_words]

def add_features(df):
    df["word_count"] = df["text"].str.split().str.len()
    return df

result = (
    df
    .pipe(remove_short, min_words=5)
    .pipe(add_features)
    .reset_index(drop=True)
)
Benchmark: On a 1M-row DataFrame, str.split().str.len() runs in ~200ms. A for loop doing the same takes ~45 seconds. 225x speedup. Always vectorize.
L10
NLP Data Pipeline with Pandas
Complete pipeline: load → clean → features → label check → split → export
+

This lesson brings everything together into a complete NLP data pipeline — the exact workflow you'd use to prepare a Turkish text classification dataset for BERT or LSTM training. From raw scraped data to train/val/test splits, ready for model input.

Python
import pandas as pd
import re
import unicodedata
from sklearn.model_selection import train_test_split

# ── STEP 1: Load raw scraped data ──
df = pd.read_csv("scraped_articles.csv", encoding="utf-8")
print(f"Raw: {len(df)} rows, {df.columns.tolist()}")

# ── STEP 2: Initial cleaning ──
df = (
    df
    .dropna(subset=["text"])
    .drop_duplicates(subset=["text"])
    .reset_index(drop=True)
)
print(f"After cleaning: {len(df)} rows")

# ── STEP 3: Text preprocessing ──
def clean_turkish(text):
    """Clean text for Turkish NLP pipeline."""
    text = unicodedata.normalize("NFC", str(text))
    text = text.replace("I", "ı").replace("İ", "i").lower()
    text = re.sub(r"https?://\S+", "", text)
    text = re.sub(r"[\w.+-]+@[\w-]+\.[\w.]+", "", text)
    text = re.sub(r"<[^>]+>", "", text)
    text = re.sub(r"[^\w\sçğıöşüÇĞİÖŞÜ]", " ", text)
    text = re.sub(r"\s+", " ", text).strip()
    return text

df["text_clean"] = df["text"].apply(clean_turkish)

# ── STEP 4: Feature engineering ──
df["word_count"] = df["text_clean"].str.split().str.len()
df["char_count"] = df["text_clean"].str.len()
df = df[(df["word_count"] >= 10) & (df["word_count"] <= 512)]
print(f"After length filter: {len(df)} rows")

# ── STEP 5: Label distribution check ──
print("\nLabel distribution:")
print(df["label"].value_counts())
print(f"Balance: {df['label'].value_counts(normalize=True).round(3).to_dict()}")

# ── STEP 6: Train / Val / Test split (70/15/15) ──
train_df, temp_df = train_test_split(
    df, test_size=0.3, random_state=42, stratify=df["label"]
)
val_df, test_df = train_test_split(
    temp_df, test_size=0.5, random_state=42, stratify=temp_df["label"]
)
print(f"\nTrain: {len(train_df)}, Val: {len(val_df)}, Test: {len(test_df)}")

# ── STEP 7: Export ──
for name, split in [("train", train_df), ("val", val_df), ("test", test_df)]:
    split[["text_clean", "label"]].to_csv(
        f"data/{name}.csv", index=False, encoding="utf-8"
    )
