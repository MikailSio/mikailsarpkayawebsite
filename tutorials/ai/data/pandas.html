PANDAS
DATA TOOLKIT

The backbone of data manipulation in Python. From loading CSVs to building complete NLP preprocessing pipelines — Pandas is where raw data becomes structured, clean, and ready for machine learning. Every data scientist's most-used library.

10 Lessons
Beginner → Intermediate
Prerequisites: Python Core
L01
DataFrame & Series Basics
pd.DataFrame · pd.Series · dtypes · shape · info() · describe() · head/tail · 8 min
+

A DataFrame is a 2D labeled table — think of it as a spreadsheet in Python. A Series is a single column. Together, they are the core data structures you'll use for every data task, from loading CSVs to feeding NLP models.

Python — Creating DataFrames
import pandas as pd

# Create from dict — most common way
df = pd.DataFrame({
    "text":  ["Great movie", "Terrible film", "Average show", "Loved it"],
    "label": [1, 0, 0, 1],
    "score": [0.95, 0.12, 0.48, 0.91]
})

# Quick inspection
df.shape        # (4, 3) — rows, cols
df.dtypes       # text: object, label: int64, score: float64
df.columns      # Index(['text', 'label', 'score'])
df.head(2)       # first 2 rows
df.tail(2)       # last 2 rows
df.info()       # column types, non-null counts, memory
df.describe()   # statistics for numeric columns

# Series — a single column
labels = df["label"]          # Series
labels.value_counts()          # 0: 2, 1: 2
labels.unique()                # array([1, 0])
labels.nunique()               # 2

# Create from list of dicts (e.g., scraped data)
records = [
    {"title": "BERT Paper", "year": 2018},
    {"title": "GPT-3 Paper", "year": 2020},
]
papers = pd.DataFrame(records)
NLP Pattern: When you scrape text data with BeautifulSoup, you typically collect a list of dicts — pd.DataFrame(records) converts it instantly into a structured table you can clean and export.
L02
Indexing & Selection
loc · iloc · boolean indexing · query() · at/iat · MultiIndex · 10 min
+

Selecting the right rows and columns is the most frequent Pandas operation. loc uses labels, iloc uses integer positions, and boolean indexing lets you filter with conditions — essential for splitting datasets and extracting subsets.

Python — loc, iloc & Boolean Indexing
# loc — label-based selection
df.loc[0, "text"]              # "Great movie"
df.loc[0:2, ["text", "label"]]  # rows 0-2, specific cols
df.loc[:, "score"]             # all rows, one column

# iloc — integer position-based
df.iloc[0]                     # first row (Series)
df.iloc[0:3, 0:2]             # first 3 rows, first 2 cols
df.iloc[-1]                    # last row

# Boolean indexing — filtering with conditions
positive = df[df["label"] == 1]
high_conf = df[df["score"] > 0.9]

# Multiple conditions (use & for AND, | for OR)
subset = df[(df["label"] == 1) & (df["score"] > 0.8)]

# query() — cleaner syntax for complex filters
result = df.query("label == 1 and score > 0.8")

# isin — filter by list of values
keep = df[df["label"].isin([0, 1])]

# at/iat — fast scalar access (single cell)
df.at[0, "text"]   # faster than loc for single values
df.iat[0, 0]       # by position
Common mistake: df["label"] == 1 & df["score"] > 0.8 fails due to operator precedence. Always wrap conditions in parentheses: (df["label"] == 1) & (df["score"] > 0.8).
L03
Data Cleaning
dropna · fillna · duplicated · replace · astype · rename · string methods · 10 min
+

80% of data science is cleaning data. Missing values, duplicates, wrong types, inconsistent strings — Pandas gives you the tools to handle all of it. In NLP, cleaning means the difference between a good model and garbage output.

Python — Data Cleaning
# Missing values
df.isnull().sum()              # count NaN per column
df.dropna()                    # remove rows with any NaN
df.dropna(subset=["text"])     # only drop if 'text' is NaN
df["score"].fillna(0.0)        # replace NaN with value
df.fillna({"score": 0, "label": -1})  # different fill per column

# Duplicates
df.duplicated().sum()          # count duplicate rows
df.drop_duplicates()           # remove exact duplicates
df.drop_duplicates(subset=["text"], keep="first")  # by column

# Type conversion
df["label"] = df["label"].astype(int)
df["score"] = pd.to_numeric(df["score"], errors="coerce")  # invalid → NaN

# Rename columns
df = df.rename(columns={"text": "content", "label": "sentiment"})

# Replace values
df["sentiment"] = df["sentiment"].replace({0: "negative", 1: "positive"})

# String cleaning (NLP essential)
df["content"] = (
    df["content"]
    .str.strip()
    .str.lower()
    .str.replace(r"\s+", " ", regex=True)
)

# Remove rows where text is too short
df = df[df["content"].str.len() > 10]
Pipeline tip: Chain operations for clean code: df = df.dropna(subset=["text"]).drop_duplicates("text").reset_index(drop=True). Always call .reset_index(drop=True) after filtering to avoid index gaps.
L04
GroupBy & Aggregation
groupby · agg · transform · apply · pivot_table · crosstab · 10 min
+

GroupBy is the split-apply-combine pattern: split data into groups, apply a function, combine results. It's how you compute per-class statistics, per-category counts, and aggregate metrics — fundamental for EDA before training any model.

Python — GroupBy & Aggregation
# Sample dataset
df = pd.DataFrame({
    "category": ["tech", "sports", "tech", "sports", "tech"],
    "text": ["AI news", "Match result", "GPU release", "Transfer", "LLM paper"],
    "word_count": [150, 200, 180, 90, 320],
    "score": [0.92, 0.78, 0.88, 0.65, 0.95]
})

# Basic groupby
df.groupby("category")["score"].mean()
# category
# sports    0.715
# tech      0.917

# Multiple aggregations
stats = df.groupby("category").agg(
    count=("text", "count"),
    avg_score=("score", "mean"),
    max_words=("word_count", "max"),
    total_words=("word_count", "sum")
)

# transform — returns same-size Series (for feature engineering)
df["cat_avg_score"] = df.groupby("category")["score"].transform("mean")

# pivot_table — Excel-like pivoting
pivot = df.pivot_table(
    values="score",
    index="category",
    aggfunc=["mean", "count"]
)

# crosstab — frequency tables
pd.crosstab(df["category"], df["score"] > 0.8)
NLP use case: df.groupby("label")["text"].count() instantly shows class distribution. If it's imbalanced (e.g., 90/10 split), you'll need to handle it before training (oversampling, class weights, etc.).
L05
Merge, Join & Concat
merge (inner/outer/left) · join · concat · append · 8 min
+

Real-world data lives in multiple tables. merge combines DataFrames on shared keys (like SQL JOINs), concat stacks them vertically or horizontally. You'll use these constantly when combining scraped data from different sources or adding metadata to your corpus.

Python — Merge & Concat
# Two related DataFrames
texts = pd.DataFrame({
    "id": [1, 2, 3, 4],
    "text": ["Great product", "Bad quality", "Nice design", "Poor service"]
})
labels = pd.DataFrame({
    "id": [1, 2, 3, 5],
    "sentiment": ["pos", "neg", "pos", "neg"]
})

# inner merge — only matching IDs (default)
df = texts.merge(labels, on="id", how="inner")   # 3 rows (1,2,3)

# left merge — keep all from left table
df = texts.merge(labels, on="id", how="left")    # 4 rows, id=4 has NaN

# outer merge — keep everything
df = texts.merge(labels, on="id", how="outer")   # 5 rows

# concat — stack DataFrames vertically
batch_1 = pd.DataFrame({"text": ["Hello"], "source": ["web"]})
batch_2 = pd.DataFrame({"text": ["World"], "source": ["api"]})
combined = pd.concat([batch_1, batch_2], ignore_index=True)

# Concat multiple scraped batches
batches = [pd.read_csv(f"batch_{i}.csv") for i in range(10)]
full_df = pd.concat(batches, ignore_index=True)
Always use ignore_index=True with concat to reset the index. Without it, you'll get duplicate indices which causes subtle bugs in downstream operations.
L06
String & Text Operations
str accessor · regex with str.extract · NLP preprocessing with Pandas · 10 min
+

Pandas' .str accessor lets you apply string operations to entire columns at once — no loops needed. Combined with regex, it becomes a powerful vectorized text preprocessing engine for NLP.

Python — Vectorized String Operations
df = pd.DataFrame({
    "text": [
        "  Visit https://t.co/abc for INFO!  ",
        "RT @user: Great news about #NLP",
        "Check email: test@mail.com ASAP",
        "Türkçe İçerik: Güzel bir HABER"
    ]
})

# Basic string operations (vectorized, no loops)
df["clean"] = (
    df["text"]
    .str.strip()                                      # trim whitespace
    .str.lower()                                      # lowercase
    .str.replace(r"https?://\S+", "", regex=True)     # remove URLs
    .str.replace(r"@\w+", "", regex=True)              # remove mentions
    .str.replace(r"#(\w+)", r"\1", regex=True)        # keep hashtag text
    .str.replace(r"[\w.+-]+@[\w-]+\.[\w.]+", "", regex=True)  # remove emails
    .str.replace(r"\s+", " ", regex=True)              # normalize spaces
    .str.strip()
)

# Extract patterns
df["hashtags"]  = df["text"].str.findall(r"#\w+")
df["word_count"] = df["clean"].str.split().str.len()
df["has_url"]    = df["text"].str.contains(r"https?://", regex=True)

# Filter by string content
nlp_rows = df[df["text"].str.contains("NLP", case=False, na=False)]

# str.extract — capture groups
df["first_word"] = df["clean"].str.extract(r"^(\w+)")
Performance: .str methods are vectorized — they're 10-100x faster than Python for loops on large DataFrames. For a 1M-row corpus, this is the difference between seconds and minutes.
L07
Date & Time
pd.to_datetime · dt accessor · resample · time series basics · 8 min
+

Time series data is everywhere — scraped articles have publication dates, model logs have timestamps, social media posts have creation times. Pandas' datetime tools let you parse, filter, and aggregate data by time periods.

Python — DateTime Operations
# Parse datetime strings
df = pd.DataFrame({
    "published": ["2024-01-15", "2024-03-22", "2024-07-08", "2024-12-01"],
    "title": ["BERT update", "GPT-5 news", "LLaMA 3", "Gemini 2"],
    "views": [5200, 18000, 12000, 9500]
})

# Convert to datetime
df["published"] = pd.to_datetime(df["published"])

# dt accessor — extract components
df["year"]    = df["published"].dt.year
df["month"]   = df["published"].dt.month
df["weekday"] = df["published"].dt.day_name()

# Filter by date range
mask = (df["published"] >= "2024-03-01") & (df["published"] < "2024-08-01")
q2_q3 = df[mask]

# Days since published
df["age_days"] = (pd.Timestamp.now() - df["published"]).dt.days

# Set datetime as index for resampling
ts = df.set_index("published")
monthly = ts["views"].resample("M").sum()    # monthly totals
quarterly = ts["views"].resample("Q").mean()  # quarterly average
Web scraping tip: Always parse dates immediately after scraping: df["date"] = pd.to_datetime(df["date_str"], format="%d/%m/%Y", errors="coerce"). Specify format for faster parsing and to handle locale-specific formats.
L08
Reading & Writing Data
read_csv · read_json · read_excel · to_csv · encoding · chunked reading · 8 min
+

Pandas reads and writes almost every tabular format. The key parameters for NLP work are encoding (always UTF-8 for Turkish), separator (TSV is common in NLP datasets), and chunked reading for large files that don't fit in memory.

Python — Reading & Writing
# CSV — most common
df = pd.read_csv("dataset.csv", encoding="utf-8")
df = pd.read_csv("dataset.tsv", sep="\t")             # TSV
df = pd.read_csv("data.csv", usecols=["text", "label"])  # only specific cols
df = pd.read_csv("data.csv", nrows=1000)               # first 1000 rows

# JSON — API responses, scraped data
df = pd.read_json("data.json")
df = pd.read_json("data.jsonl", lines=True)  # JSON Lines format

# Excel
df = pd.read_excel("data.xlsx", sheet_name="Sheet1")

# Write
df.to_csv("output.csv", index=False, encoding="utf-8")
df.to_json("output.json", orient="records", force_ascii=False)
df.to_json("output.jsonl", orient="records", lines=True)

# ★ Chunked reading — for large files (e.g., 10GB corpus)
chunks = pd.read_csv("huge_corpus.csv", chunksize=10_000)
results = []
for chunk in chunks:
    cleaned = chunk[chunk["text"].str.len() > 20]
    results.append(cleaned)
df = pd.concat(results, ignore_index=True)
Turkish encoding: Always pass encoding="utf-8" when reading/writing. If you see garbled characters (Ã¼ instead of ü), the file was likely saved as Latin-1: try encoding="latin-1" or encoding="cp1254" (Windows Turkish).
L09
Performance & Best Practices
vectorized ops vs loops · memory optimization · category dtype · eval/query · 8 min
+

Pandas can be slow if you use it wrong. The golden rule: never loop over rows. Use vectorized operations, choose the right dtypes, and learn when to use eval() and query() for large DataFrames.

Python — Performance Optimization
# ❌ SLOW — iterating row by row
for i, row in df.iterrows():
    df.at[i, "word_count"] = len(row["text"].split())

# ✅ FAST — vectorized operation (100x faster)
df["word_count"] = df["text"].str.split().str.len()

# ❌ SLOW — apply with Python function
df["upper"] = df["text"].apply(lambda x: x.upper())

# ✅ FAST — built-in vectorized method
df["upper"] = df["text"].str.upper()

# Memory optimization — category dtype
df["label"].memory_usage(deep=True)  # check current
df["label"] = df["label"].astype("category")  # often 90% less memory

# Downcast numeric types
df["count"] = pd.to_numeric(df["count"], downcast="integer")

# eval() — fast expression evaluation for large DataFrames
df.eval("ratio = score / word_count", inplace=True)

# query() — faster filtering syntax
result = df.query("score > 0.8 and word_count > 50")

# Check total memory usage
print(df.memory_usage(deep=True).sum() / 1024**2, "MB")
Benchmark: On a 1M-row DataFrame, str.split().str.len() runs in ~200ms. A for loop doing the same takes ~45 seconds. That's a 225x speedup. Always vectorize.
L10
NLP Data Pipeline with Pandas
Complete pipeline: load → clean → label → split → export · 12 min
+

This lesson brings everything together into a complete NLP data pipeline — the exact workflow you'd use to prepare a Turkish text classification dataset for BERT or LSTM training. From raw scraped data to train/val/test splits, ready for model input.

Python — Complete NLP Data Pipeline
import pandas as pd
import re
import unicodedata
from sklearn.model_selection import train_test_split

# ── STEP 1: Load raw scraped data ──
df = pd.read_csv("scraped_articles.csv", encoding="utf-8")
print(f"Raw: {len(df)} rows, {df.columns.tolist()}")

# ── STEP 2: Initial cleaning ──
df = df.dropna(subset=["text"])                # remove missing text
df = df.drop_duplicates(subset=["text"])       # remove exact duplicates
df = df.reset_index(drop=True)

# ── STEP 3: Text preprocessing ──
def clean_turkish(text):
    """Clean text for Turkish NLP pipeline."""
    text = unicodedata.normalize("NFC", str(text))
    text = text.replace("I", "ı").replace("İ", "i").lower()
    text = re.sub(r"https?://\S+", "", text)
    text = re.sub(r"[\w.+-]+@[\w-]+\.[\w.]+", "", text)
    text = re.sub(r"<[^>]+>", "", text)
    text = re.sub(r"[^\w\sçğıöşüÇĞİÖŞÜ]", " ", text)
    text = re.sub(r"\s+", " ", text).strip()
    return text

df["text_clean"] = df["text"].apply(clean_turkish)

# ── STEP 4: Feature engineering ──
df["word_count"] = df["text_clean"].str.split().str.len()
df["char_count"] = df["text_clean"].str.len()

# Remove too-short or too-long texts
df = df[(df["word_count"] >= 10) & (df["word_count"] <= 512)]

# ── STEP 5: Label distribution check ──
print("Label distribution:")
print(df["label"].value_counts())
print(f"\nClass balance: {df['label'].value_counts(normalize=True).round(3).to_dict()}")

# ── STEP 6: Train / Val / Test split ──
train_df, temp_df = train_test_split(
    df, test_size=0.3, random_state=42, stratify=df["label"]
)
val_df, test_df = train_test_split(
    temp_df, test_size=0.5, random_state=42, stratify=temp_df["label"]
)

print(f"Train: {len(train_df)}, Val: {len(val_df)}, Test: {len(test_df)}")

# ── STEP 7: Export for model training ──
for name, split in [("train", train_df), ("val", val_df), ("test", test_df)]:
    split[["text_clean", "label"]].to_csv(
        f"data/{name}.csv", index=False, encoding="utf-8"
    )
print("✓ Pipeline complete — data exported to data/")
Key decisions: Use stratify in train_test_split to maintain class balance across splits. A typical NLP split is 70/15/15 (train/val/test). For small datasets (<5K samples), consider 5-fold cross-validation instead.
