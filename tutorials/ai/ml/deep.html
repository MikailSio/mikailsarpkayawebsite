LEARNING

From single neurons to deep architectures. Understand backpropagation, activation functions, CNNs, and how to build and train neural networks with PyTorch. The foundation for everything in modern NLP and computer vision.

Level: Intermediate
Lessons: 7
Framework: PyTorch
L01
Perceptron & Neural Networks
Single neuron · Multi-layer perceptron · Forward pass · Universal approximation · 10 min
+

A perceptron is the simplest neural unit: it takes inputs x₁...xₙ, multiplies each by a weight wᵢ, adds a bias b, and passes the result through an activation function. A single perceptron can only learn linearly separable patterns.

Neuron output: z = Σ(wᵢ·xᵢ) + b, then a = σ(z) where σ is the activation function.

A Multi-Layer Perceptron (MLP) stacks multiple layers of neurons: input layer → hidden layers → output layer. The Universal Approximation Theorem states that a network with at least one hidden layer can approximate any continuous function — given enough neurons.

Python — Neural Network with PyTorch
import torch
import torch.nn as nn

# Define a 3-layer MLP
class MLP(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, output_dim)
        )

    def forward(self, x):
        return self.net(x)

# Create model: 10 input features, 64 hidden, 2 classes
model = MLP(10, 64, 2)
print(model)
print(f"Parameters: {sum(p.numel() for p in model.parameters()):,}")
L02
Activation Functions
ReLU · Sigmoid · Tanh · LeakyReLU · GELU · Softmax · 8 min
+

Activation functions introduce non-linearity into the network. Without them, stacking linear layers would just produce another linear transformation — no matter how many layers you add.

ReLU f(x) = max(0, x) — the default choice for hidden layers. Fast, avoids vanishing gradient for positive values. Sigmoid σ(x) = 1/(1+e⁻ˣ) — squashes to (0,1), used in binary output layers. Tanh — squashes to (-1,1), zero-centered. GELU — used in BERT and modern transformers, smoother than ReLU. Softmax — converts logits to probability distribution, used for multi-class output layers.

Python — Activations in PyTorch
import torch
import torch.nn.functional as F

x = torch.tensor([-2.0, -1.0, 0.0, 1.0, 2.0])

print("ReLU:    ", F.relu(x))
print("Sigmoid: ", torch.sigmoid(x))
print("Tanh:    ", torch.tanh(x))
print("GELU:    ", F.gelu(x))
print("Softmax: ", F.softmax(x, dim=0))

# LeakyReLU — prevents "dying ReLU" problem
print("LeakyReLU:", F.leaky_relu(x, negative_slope=0.01))
Rule of thumb: Use ReLU for hidden layers (or LeakyReLU/GELU). Use Sigmoid for binary classification output. Use Softmax for multi-class output. Use GELU in transformer architectures.
L03
Backpropagation & Chain Rule
Computational graph · Autograd · Loss backward · Weight updates · 12 min
+

Backpropagation is how neural networks learn. It computes the gradient of the loss function with respect to each weight by applying the chain rule of calculus — propagating error signals backward from output to input.

Chain rule: ∂L/∂w₁ = (∂L/∂a₃) · (∂a₃/∂z₃) · (∂z₃/∂a₂) · (∂a₂/∂z₂) · (∂z₂/∂w₁) — each factor corresponds to one layer.

PyTorch's autograd engine builds a computational graph dynamically and computes all gradients automatically with .backward().

Python — Training Loop
import torch
import torch.nn as nn

# Simple model, loss, optimizer
model = nn.Sequential(nn.Linear(10, 32), nn.ReLU(), nn.Linear(32, 2))
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

# Dummy data
X = torch.randn(64, 10)   # batch of 64, 10 features
y = torch.randint(0, 2, (64,))  # labels: 0 or 1

# Training step
for epoch in range(100):
    optimizer.zero_grad()         # 1. Clear old gradients
    logits = model(X)             # 2. Forward pass
    loss = criterion(logits, y)   # 3. Compute loss
    loss.backward()               # 4. Backprop (compute gradients)
    optimizer.step()              # 5. Update weights

    if epoch % 20 == 0:
        acc = (logits.argmax(1) == y).float().mean()
        print(f"Epoch {epoch:3d} | Loss: {loss:.4f} | Acc: {acc:.2%}")
Always call optimizer.zero_grad() before loss.backward(). Otherwise gradients accumulate across iterations, causing incorrect updates.
L04
Loss Functions & Metrics
CrossEntropy · MSE · BCE · F1 · Precision · Recall · Confusion Matrix · 10 min
+

The loss function defines what the network optimizes. Different tasks require different losses:

CrossEntropyLoss — multi-class classification (combines LogSoftmax + NLLLoss). BCEWithLogitsLoss — binary classification (combines Sigmoid + BCE). MSELoss — regression tasks.

Python — Loss Functions & Evaluation
import torch.nn as nn
from sklearn.metrics import (
    classification_report, confusion_matrix, f1_score
)

# Multi-class: CrossEntropyLoss (expects raw logits)
ce_loss = nn.CrossEntropyLoss()
logits = torch.randn(8, 5)   # 8 samples, 5 classes
labels = torch.randint(0, 5, (8,))
loss = ce_loss(logits, labels)

# Binary: BCEWithLogitsLoss
bce_loss = nn.BCEWithLogitsLoss()
logits_bin = torch.randn(8, 1)
labels_bin = torch.randint(0, 2, (8, 1)).float()
loss_bin = bce_loss(logits_bin, labels_bin)

# Evaluation metrics (after model prediction)
y_true = [0,1,1,0,1,0,1,1]
y_pred = [0,1,0,0,1,1,1,1]
print(classification_report(y_true, y_pred))
print("Confusion Matrix:")
print(confusion_matrix(y_true, y_pred))
print(f"F1 (macro): {f1_score(y_true, y_pred, average='macro'):.3f}")
For NLP classification: Use F1 score (especially macro-F1) rather than accuracy when classes are imbalanced — which is almost always the case in real text classification tasks.
L05
Optimizers & Learning Rate
SGD · Adam · AdamW · Learning rate scheduling · Weight decay · 10 min
+

Optimizers determine how weights are updated based on gradients. SGD is the classic: θ = θ − α·∇J. Adam (Adaptive Moment Estimation) combines momentum and RMSProp — it maintains per-parameter learning rates using first and second moment estimates. AdamW decouples weight decay from the gradient update — the standard for fine-tuning transformers.

Python — Optimizers & Schedulers
import torch.optim as optim

# Common optimizers
opt_sgd  = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
opt_adam = optim.Adam(model.parameters(), lr=1e-3)
opt_adamw = optim.AdamW(model.parameters(), lr=2e-5, weight_decay=0.01)

# Learning rate schedulers
scheduler = optim.lr_scheduler.StepLR(opt_adam, step_size=10, gamma=0.5)
# Reduce LR by half every 10 epochs

# Cosine annealing (common in transformer training)
scheduler_cos = optim.lr_scheduler.CosineAnnealingLR(
    opt_adamw, T_max=50, eta_min=1e-6
)

# In training loop:
# optimizer.step()
# scheduler.step()  ← call after each epoch
For transformer fine-tuning: Use AdamW with lr=2e-5 to 5e-5, weight_decay=0.01, and a linear warmup scheduler. This is the standard recipe from the BERT paper.
L06
Convolutional Neural Networks (CNN)
Convolution · Pooling · Feature maps · 1D-CNN for text · 12 min
+

CNNs use learnable filters (kernels) that slide over the input to detect local patterns. In images: edges, textures, shapes. In text: n-gram patterns. Key operations: Convolution (pattern detection) → Activation (ReLU) → Pooling (downsampling).

1D-CNN for NLP: Apply 1D convolutions over word embedding sequences. Different kernel sizes capture different n-gram patterns (bigrams, trigrams, etc.). Used in text classification before transformers became dominant.

Python — 1D-CNN for Text Classification
import torch
import torch.nn as nn

class TextCNN(nn.Module):
    def __init__(self, vocab_size, embed_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)

        # Multiple kernel sizes → capture different n-grams
        self.conv3 = nn.Conv1d(embed_dim, 100, kernel_size=3)
        self.conv4 = nn.Conv1d(embed_dim, 100, kernel_size=4)
        self.conv5 = nn.Conv1d(embed_dim, 100, kernel_size=5)
        self.dropout = nn.Dropout(0.5)
        self.fc = nn.Linear(300, num_classes)

    def forward(self, x):
        # x: (batch, seq_len)
        x = self.embedding(x)          # (batch, seq_len, embed)
        x = x.permute(0, 2, 1)         # (batch, embed, seq_len)

        c3 = torch.relu(self.conv3(x)).max(dim=2).values
        c4 = torch.relu(self.conv4(x)).max(dim=2).values
        c5 = torch.relu(self.conv5(x)).max(dim=2).values

        out = torch.cat([c3, c4, c5], dim=1)
        out = self.dropout(out)
        return self.fc(out)

model = TextCNN(vocab_size=30000, embed_dim=128, num_classes=5)
print(f"Parameters: {sum(p.numel() for p in model.parameters()):,}")
L07
Dropout, Batch Norm & Overfitting
Dropout · BatchNorm · LayerNorm · Early stopping · Data augmentation · 10 min
+

Dropout randomly zeroes a fraction of neuron outputs during training — forces the network to not rely on any single neuron. At inference, all neurons are active but outputs are scaled. Standard rates: 0.1-0.5.

Batch Normalization normalizes the input to each layer across the batch — stabilizes training and allows higher learning rates. Layer Normalization normalizes across features (not batch) — standard in transformers since batch size can be small.

Early stopping: Monitor validation loss during training. Stop when it starts increasing (overfitting). Save the checkpoint with the best validation performance.

Python — Regularization Techniques
import torch.nn as nn

# Model with regularization
model = nn.Sequential(
    nn.Linear(784, 256),
    nn.BatchNorm1d(256),    # Batch Normalization
    nn.ReLU(),
    nn.Dropout(0.3),         # Dropout 30%
    nn.Linear(256, 128),
    nn.BatchNorm1d(128),
    nn.ReLU(),
    nn.Dropout(0.3),
    nn.Linear(128, 10)
)

# IMPORTANT: toggle between train/eval modes
model.train()  # dropout ON, batchnorm uses batch stats
model.eval()   # dropout OFF, batchnorm uses running stats

# Early stopping (pseudo-code)
best_val_loss = float('inf')
patience, counter = 5, 0
for epoch in range(100):
    train_loss = train_one_epoch()
    val_loss   = evaluate()
    if val_loss < best_val_loss:
        best_val_loss = val_loss
        counter = 0
        torch.save(model.state_dict(), "best_model.pt")
    else:
        counter += 1
        if counter >= patience:
            print("Early stopping!")
            break
Always call model.eval() before inference/testing and model.train() before training. Forgetting this is one of the most common PyTorch bugs — it silently degrades performance.
