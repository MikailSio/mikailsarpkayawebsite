The Project Philosophy
What's inside

Built like a textbook,
rendered like a product.

Every page is held to the same pedagogical bar: concept, intuition, mathematics, code, example. No filler, no syllabus dumps — only what an engineer needs to think clearly and ship correctly.

Real Code, Real Output

Every snippet is runnable Python, NumPy, PyTorch, or HuggingFace — paired with the explanation of what it does and why, line by line.

Math, Properly Typeset

KaTeX-rendered formulas with full symbol-by-symbol breakdowns. Cross-entropy, attention, gradient descent — derived, not just shown.

Bilingual EN + TR

One Sidebar, Full Map

Theme & Accent

Dark, light, and ten preset accent colors — including a custom picker. The site reads the way you read.
